# SG-Finance

SG-Finance adalah aplikasi Point of Sale (Kasir Pintar) dan Enterprise Resource Planning (ERP) berbasis web modern.
Aplikasi ini dibuat menggunakan React dan Vite.

## Fitur
- **Kasir (POS)**: Manajemen penjualan dengan keranjang dan fitur checkout.
- **Buku Besar (Ledger)**: Pencatatan otomatis jurnal keuangan (pemasukan & pengeluaran).
- **Inventaris**: Pelacakan stok otomatis, sinkronisasi dengan setiap transaksi penjualan.
- **Laporan**: Visualisasi data ringkasan usaha dengan antarmuka yang modern.
- **Personalisasi Akun**: Mengganti nama bisnis dan avatar kasir dengan mudah.

## Menjalankan Aplikasi
```bash
npm install
npm run dev
```
