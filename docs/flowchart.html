Flowchart Transaksi Kasir (POS)

flowchart TD
    Start([Mulai Transaksi]) --> SelectItem[Pilih Produk di Keranjang]
    SelectItem --> CheckStock{Stok Cukup?}
    CheckStock -- Tidak --> Error[Tolak & Tampilkan Pesan Error]
    CheckStock -- Ya --> AddCart[Tambahkan ke Keranjang]
    
    AddCart --> MoreItems{Tambah Produk Lain?}
    MoreItems -- Ya --> SelectItem
    MoreItems -- Tidak --> Checkout[Klik Tombol Bayar]
    
    Checkout --> Calculate[Hitung Subtotal, PPN 11%, dan Total]
    Calculate --> DeductStock[Otomatis Kurangi Stok Inventaris]
    
    DeductStock --> StockAlert{Sisa Stok <= 5?}
    StockAlert -- Ya --> SendNotif[Kirim Notifikasi Stok Menipis]
    StockAlert -- Tidak --> RecordSale
    
    SendNotif --> RecordSale
    RecordSale --> RecordJournal[Otomatis Catat Pendapatan di Buku Besar]
    RecordJournal --> RecordTax[Otomatis Catat Hutang PPN di Buku Besar]
    RecordTax --> ClearCart[Kosongkan Keranjang Kasir]
    ClearCart --> ShowSuccess[Tampilkan Struk/Pop-up Sukses]
    ShowSuccess --> End([Selesai])
